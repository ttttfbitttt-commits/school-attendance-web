# الجدول الصوتي — نسخة تجريبية محلية

## وضع النشر المستقل

يدعم الخادم وضعًا متعدد المدارس عند تشغيله مع `SOUNDTABLE_AUTH=1`. لكل حساب مدرسة سجل مشروع مستقل في قاعدة SQLite، ولا تُقرأ بيانات مدرسة من حساب آخر. يمكن إنهاء الجلسة من زر «تسجيل الخروج» داخل التطبيق. التسجيل يستخدم البريد وكلمة المرور، ولا يفتح الحساب قبل تأكيد البريد عبر Resend. انسخ `.env.example` إلى إعدادات الخادم، واستخدم نطاقًا مستقلًا مثل `soundtable.example.com`، ولا تشارك قاعدة بيانات نظام الحصر معه.

يحتاج النشر إلى نطاق HTTPS وبريد مرسل موثّق في Resend. لا تضع `RESEND_API_KEY` داخل الملفات أو المستودع؛ مرّره كمتغير سري في خدمة التشغيل. يوجد إعداد Docker مستقل في `docker-compose.soundtable.yml`، ويُفضَّل تشغيله خلف Nginx على نطاق مثل `soundtable.7asr2030.com` وبقاعدة بيانات مختلفة تمامًا عن نظام الحصر.

تشغيل على Windows من هذا المجلد:

```powershell
.\.venv\Scripts\python.exe server.py
```

افتح http://127.0.0.1:8767 . الاستماع محلي فقط. لا يُنشر هذا الخادم التجريبي على الإنترنت؛ ليس خادم إنتاج ولا يحتوي مصادقة متعددة المستخدمين.

عند أول تشغيل يبدأ المشروع فارغًا. ينشئ المستخدم الفصول من أعداد الشعب ثم يستورد أسماء المعلمين من Excel مع معاينة قبل الإضافة. لا تُستورد إغلاقات المعلمين تلقائيًا. تُحفظ المسودة محليًا في `data/project.json`. عند ترقية النسخة السابقة تحفظ بياناتها في ملف `data/legacy-*.json` قبل بدء الإعداد الجديد.

التثبيت عند الحاجة:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

الاختبارات: `.\.venv\Scripts\python.exe -m unittest -v`.

## يعمل الآن

- إنشاء الشعب من أعداد الفصول واستيراد أسماء المعلمين وأنصبتهم واختصاراتهم من Excel مع معاينة.
- معالج عربي متدرج، وتخصيص توقيت وأنصبة وإسناد وإتاحة وحفظ محلي برقم مراجعة.
- محرك CP-SAT فعلي مع حالات نجاح وتعذر وعدم حسم، ومدقق منفصل أساسي للنتيجة.
- سحب باليد مع معاينة حتى ثلاثة بدائل نقل وجداول المعلمين الأسبوعية قبل وبعد، وتصنيف بسيط (حتى حصتين) ومركب (3–4) ومركب مضاعف (5 فأكثر)، وتنفيذ وتراجع. البحث محدود بمهلة ولا يحصر جميع البدائل.
- في محرر تعديل الجدول، يمكن تحديد المعلم بقول اسمه أو «اختر المعلم» ثم اسمه؛ وعند تشابه الاسم مع عدة معلمين يفضّل المساعد المعلم المعروض حاليًا أو يطلب كلمة تميّزه. اختر الحصة بذكر يومها ورقمها، مثل «اختر الحصة الرابعة يوم الأحد»، ثم قل «انقلها إلى الحصة الثانية يوم الأربعاء». ويمكن نقل مادة محددة بقول «انقل مادة الرياضيات لفصل أول 1 من يوم الأحد الحصة الثالثة إلى يوم الاثنين الحصة الرابعة»؛ تُقبل أرقام الحصص أو أسماؤها الترتيبية. تعرض المعاينة أثر النقل ولا يُعتمد إلا بعد اختيار تنفيذ التبديل.
- مساعد صوتي عربي يطابق الأوامر والسياق، ويقبل إسناد الفصل المختار بذكر اسمه مباشرةً؛ مثل «ثاني 7»، «ثاني سابع»، «ثانيه سابع» و«ثانيا سابع». وتبقى أزرار الواجهة القابلة للتنفيذ متاحة بقول «اضغط» ثم الاسم الظاهر.
- بعد الإسناد، يمكن حفظ الخطوة والانتقال صوتيًا بقول «حفظ ومتابعة» أو «التالي» أو «اللي بعده» أو «انتقل للمرحلة التالية». ويمكن الانتقال إلى تبويب محدد بقول «انتقل للتبويب» ثم اسمه.
- في الإتاحة والقيود، يمكن اختيار المعلم بمجرد قول اسمه أو بجزء مميز منه، ثم قول «بدون سابعة» أو «بدون سوادس وبدون سوابع» أو «فرغه من الأولى» لمنع الحصة في أيام الدوام، أو «إلى الرابعة» لمنع ما بعدها، أو «المعلم منتدب» لمنع جميع حصصه. يمكن تحديد اليوم بقول «الخميس متاح» لإتاحة كل حصصه، أو «الخميس الحصة الأولى» لتبديل حالة تلك الحصة، أو «الخميس الحصة الأولى غير متاح» لمنعها؛ وتُقبل أوامر «متاح كل الأيام» و«كل الأيام بدون سادسة». يمكن قول «من الأولى إلى الرابعة غير متاح» لمنع نطاق، أو «متاح من الأولى إلى الرابعة بحيث يلغي البقية» لإتاحة النطاق ومنع ما عداه، أو ذكر نطاق/حصة مجردة لتبديل حالتها. تدعم الأوامر قوائم الحصص مثل «بدون أولى وثانية وثالثة ورابعة». أوامر حفظ ومتابعة والتنقل بين الخطوات لها أولوية على مطابقة الأسماء. تُرفض القيود التي تتعارض مع نصاب المعلم الحالي.
- مطابقة أسماء المعلمين توحّد كتابة الأسماء المركبة المبدوءة بـ«عبد»، مثل «عبدالرحمن» و«عبد الرحمن» و«عبدالعزيز» و«عبد العزيز» و«عبدالله» و«عبد الله»، وتطلب توضيحًا عند وجود أكثر من مرشح مطابق.
- في شاشة إسناد المعلمين، يمكن إسناد كل فصول صف أو إلغاء إسناد فصل/صف بعبارات مثل «ثالث ثانوي كلهم»، «جميع فصول ثالث ما عدا ثالث 7»، «ألغِ ثالث 7» و«شيل ثالث ثانوي كلهم». تُفحص الحجوزات ونصاب المعلم قبل تطبيق الدفعة، وتُرفض العملية كاملة إذا تعذر تطبيقها بأمان.
- الإملاء الصوتي يستخدم خدمة التعرف التي يوفرها المتصفح للغة العربية؛ أما صيغ الأوامر ومعانيها فتُعرّف في ملفات الواجهة ولا يتعلمها التطبيق تلقائيًا من المحادثات أو يخزن تسجيلات صوتية كتدريب.

## لم يكتمل

نسخة Copilot المحلية تدعم تسجيل دخول GitHub واختبارًا وأدوات محدودة للبحث عن معلم وطلب فتح التبويبات والنوافذ أو جدول المعلم. لا تملك أدوات تعديل أو حذف، ولا تنفذ إنشاء الجدول. لا يوجد ربط بـChatGPT؛ ربط ChatGPT plan usage لتطبيق مستضاف يتطلب موافقة OpenAI. القوالب الرسمية لكل المراحل والطباعة الاحترافية الشاملة ما تزال ضمن التطوير. الطباعة الحالية لليوم المعروض فقط. التوقيت الحالي موحد للفصول؛ التوقيتات المتباينة تحتاج نموذج موارد زمني أوسع قبل إعلان دعمها.

## Copilot — تجربة محلية

يتطلب الربط إنشاء GitHub OAuth App محليًا. الخطوات التالية تستخدم المنفذ `8768` لتجنب إيقاف خادم آخر قد يشغل `8767`. اضبط الصفحة الرئيسية على `http://127.0.0.1:8768/` وعنوان العودة على `http://127.0.0.1:8768/auth/copilot/callback`.

```powershell
.\start_copilot_dev.ps1
```

إذا قال المشغّل إن المنفذ مستخدم، أوقف الخادم القديم بـ`Ctrl+C` في طرفيته ثم أعد تشغيل المشغّل. سيطلب Client ID أولًا ثم Client Secret بإدخال مخفي. لا تكتب القيم داخل الأمر أو ترسلها في محادثة.

في GitHub OAuth App استخدم الصفحة الرئيسية `http://127.0.0.1:8768/` وعنوان callback المطابق أعلاه. إذا غيّرت المنفذ، حدّث `NASQ_PORT` و`GITHUB_REDIRECT_URI` وعنوان callback معًا.

لا ترسل Client Secret أو رموز الدخول في المحادثات ولا تضفها إلى الملفات. من زر «ربط المساعد» اختر «متابعة مع GitHub Copilot». الحساب يحتاج صلاحية Copilot فعالة؛ وقد يطلب GitHub مراجعة أو موافقة المؤسسة. ChatGPT plan usage غير مفعل: التطبيقات التجارية المستضافة تحتاج موافقة OpenAI على Sign in with ChatGPT.

هذه النسخة محلية لمتصفح واحد؛ رمز GitHub وسياق المحادثة تحفظهما وحدة التطوير في الذاكرة لكل جلسة، ويُحذفان عند الفصل أو إعادة تشغيل الخادم. ليست جاهزة لنشر متعدد المدارس. قبل دمجها مع الموقع المنشور يجب ربط جلسة Copilot بهوية المدرسة الموثقة في خادم الإنتاج، وتخزين/تدوير رموز OAuth في مخزن أسرار معتمد، وتفعيل HTTPS وحدود الاستخدام وعزل الجلسات. لا تستخدم مفتاحًا مشتركًا أو كلمة مرور GitHub.

تجربة المدرسة لا تتطلب تخفيف إغلاقاتها تلقائيًا؛ إذا تعذرت، يعرض المحرك الحالة ولا يغير القيود دون قرار. لا يدعي أفضلية عالمية للنتيجة عند الحالة FEASIBLE.

التوليد يبدأ بمحاولة بلا تكرار يومي للمادة خلال مهلة قصيرة، ثم يعود إلى بحث يسمح بالتكرار عند الحاجة. الإغلاقات قيود قطعية مباشرة. الزمن يعتمد على القيود والجهاز؛ لا يضمن أجزاء الثانية لكل حالة.
